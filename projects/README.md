# Проекты портфолио

Библиотека проектов, не привязанная к конкретному сайту. Каждый проект — отдельная папка
с описанием `project.json` и скриншотами. Папку можно скопировать на другой сайт как есть:
в файлах нет ничего, что зависит от вёрстки, текстов или списка проектов этого сайта.

Какие проекты показывать и в каком порядке, решает сайт (здесь — `content/site.json`,
поле `projects`).

```
projects/
  the750/
    project.json
    home.jpg
    collection.jpg
  madrekunst/
    ...
```

Имя папки — это идентификатор проекта (латиница, без пробелов).

## Языки

Любое текстовое значение может быть:

- **строкой** — одинаково на всех языках: `"brand": "THE 750"`
- **объектом по языкам** — `"role": { "ru": "Моя роль", "en": "My role" }`

Языков может быть сколько угодно, ключи — коды языков (`ru`, `en`, `de`…). Если перевода
на нужный язык нет, сайт берёт язык по умолчанию.

## project.json

```json
{
  "brand": "Название бренда",
  "brandDescription": { "ru": "Кто они и чем занимаются", "en": "Who they are" },
  "year": 2024,
  "url": "https://example.com/",
  "platform": "Shopify",
  "role": { "ru": "Моя роль в проекте", "en": "My role in the project" },
  "summary": { "ru": "Коротко о проекте", "en": "Short project summary" },
  "stack": ["Shopify", "Liquid", { "ru": "МойСклад", "en": "MoySklad" }],
  "tasks": {
    "ru": ["Что сделано 1", "Что сделано 2"],
    "en": ["What I did 1", "What I did 2"]
  },
  "screenshots": [
    { "file": "home.jpg", "title": { "ru": "Главная", "en": "Home page" } },
    { "file": "product.jpg", "title": { "ru": "Карточка товара", "en": "Product page" } }
  ],
  "hidden": false
}
```

| Поле | Обязательно | Что это |
|---|---|---|
| `brand` | да | Название бренда / клиента |
| `brandDescription` | | Одна фраза о бренде |
| `year` | | Год или период: `2024`, `"2018–2021"` |
| `url` | | Ссылка на сайт |
| `platform` | | Платформа или несколько: `"Shopify"`, `["Shopify", "Advantshop"]` |
| `role` | | Моя роль, если делала не весь проект |
| `summary` | | Коротко о проекте (1–2 предложения) |
| `stack` | | Технологии — список тегов |
| `tasks` | | Что сделано — список пунктов (см. ниже) |
| `screenshots` | да, от 2 | Скриншоты; первый — обложка |
| `hidden` | | `true` — не показывать проект на сайте |

### tasks

Простой список пунктов или группы с подзаголовками (например, когда в проекте несколько сайтов):

```json
"tasks": {
  "ru": [
    { "title": "Международный сайт — Shopify", "items": ["Пункт 1", "Пункт 2"] },
    { "title": "Российский сайт — Advantshop", "items": ["Пункт 1"] }
  ],
  "en": [ ... ]
}
```

### screenshots

| Поле | Что это |
|---|---|
| `file` | Имя файла в папке проекта (JPG, PNG, WebP) |
| `title` | Подпись вкладки |
| `url` | Адрес в рамке браузера, если он отличается от `url` проекта |

Скриншоты: ширина 1000–1600 px, JPG/WebP, до ~1 МБ. Длинные скриншоты всей страницы —
нормально, сайт показывает их с прокруткой.
